## 1. AS-IS — 현재 위페어 입고 등록 흐름

```
[사용자: 공업사 직원]

[앱 실행]
    │
    ▼
[작업목록 화면] ─── 하단 탭 "입고등록" 탭 탭
    │
    ▼
[입고등록 화면]
    │
    ├── [앨범 열기] → 사진 선택 → 업로드
    │
    ├── [OCR 차량번호 인식] → 차량번호 자동 입력
    │        └── OCR 실패 → 수기 입력
    │
    ├── [차종 수기 입력]
    │
    └── [입고등록 완료 버튼 탭]
             │
             ▼
         [작업목록 화면] ← 신규 카드 추가됨
```

**중복 작업 발생 지점:**
- AOS 알파에서 이미 완료된 작업: 차량번호 인식, 차종 확인, 초기 사진 촬영
- 위페어에서 동일 작업 재수행 필요 → **이중 입력 부담**

## 2. TO-BE (자동) — 앱 실행 시 AOS 자동 반영 흐름

```
[사용자: 공업사 직원]

[위페어 파트너스 앱 실행]
    │
    ▼
[시스템: AIAOS전송 폴더 스캔] ←─────────────────────────────┐
    │                                                         │
    ├── 신규 폴더 없음 ──────────────────────────────────────┤
    │        └── 기존 작업목록 그대로 표시                    │
    │                                                         │
    └── 신규 "차량번호_차종" 폴더 감지                       │
             │                                                │
             ▼                                               │
    [시스템: 폴더명 파싱]                                    │
             │                                               │
             ├── 차량번호 추출 (앞부분)                      │
             └── 차종명 추출 및 정규화 (뒷부분)              │
             │                                               │
             ▼                                               │
    [시스템: 중복 차량 확인]                                 │
             │                                               │
             ├── 동일 차량번호 이미 등록됨                   │
             │        └── 중복 등록 건너뜀 (무시)            │
             │                                               │
             └── 신규 차량 확인                              │
                      │                                      │
                      ▼                                      │
             [시스템: 위페어 입고 등록 API 호출]             │
                      │                                      │
                      ├── API 성공                           │
                      │        │                             │
                      │        ▼                             │
                      │   [대표사진 업로드 (1번째 사진)]     │
                      │        │                             │
                      │        ▼                             │
                      │   [나머지 초기사진 업로드]           │
                      │        │                             │
                      │        ▼                             │
                      │   [작업목록 자동 갱신]               │
                      │        │                             │
                      │        ▼                             │
                      │   [토스트 표시: "N건 입고 반영됨"]   │
                      │                                      │
                      └── API 실패                           │
                               │                             │
                               ▼                             │
                          [토스트: "AOS 연동 실패. 수동 연동을 시도해 주세요"]
                               │                             │
                               └─────────────────────────────┘

[작업목록 화면 표시]
    │
    └── 자동 반영된 카드: "AOS" 배지 표시
```

**분기 조건 정리:**

| 조건 | 시스템 동작 |
|---|---|
| 신규 폴더 없음 | 스캔 종료, 기존 목록 유지 |
| 신규 폴더 감지 | 파싱 → API 호출 → 업로드 |
| 차량번호 중복 | 해당 건 건너뜀, 나머지 진행 |
| 사진 폴더 비어있음 | 차량 정보만 등록, 사진 없이 완료 |
| 네트워크 오류 | 실패 토스트 표시, 수동 연동 유도 |
| AOS 폴더 없음 (권한 없음 포함) | 에러 없이 종료, 사용자 알림 없음 |

## 3. TO-BE (수동) — 작업목록 내 수동 연동 버튼 사용 흐름

```
[사용자: 공업사 직원]

[작업목록 화면]
    │
    └── 필터 영역 우측 "AOS 불러오기" 버튼 탭
             │
             ▼
    [버튼 상태: 로딩 스피너로 전환]
    [시스템: AIAOS전송 폴더 스캔 시작]
             │
             ├── 폴더 접근 권한 없음
             │        │
             │        ▼
             │   [바텀시트 or 토스트: "AOS 폴더에 접근할 수 없어요. 권한을 확인해 주세요"]
             │
             ├── 신규 데이터 없음
             │        │
             │        ▼
             │   [토스트: "새로 불러올 입고 데이터가 없어요"]
             │
             └── 신규 데이터 있음
                      │
                      ▼
             [시스템: 폴더명 파싱 → 중복 확인 → API 호출]
                      │
                      ├── 성공
                      │        │
                      │        ▼
                      │   [사진 업로드]
                      │        │
                      │        ▼
                      │   [작업목록 갱신]
                      │        │
                      │        ▼
                      │   [토스트: "N건 입고를 불러왔어요"]
                      │   [버튼 상태: 완료 아이콘 → 2초 후 기본 상태 복귀]
                      │
                      └── 일부 실패 (N건 중 M건 실패)
                               │
                               ▼
                          [토스트: "N건 중 M건 불러오기에 실패했어요"]
                          [버튼 상태: 기본 상태 복귀]
```

**분기 조건 정리:**

| 조건 | 사용자 액션 | 시스템 동작 |
|---|---|---|
| 버튼 탭 | 버튼 탭 | 로딩 상태 전환 + 스캔 시작 |
| 진행 중 재탭 | 버튼 탭 (비활성 상태) | 무시 (중복 실행 방지) |
| 폴더 권한 없음 | — | 권한 안내 토스트/바텀시트 |
| 신규 없음 | — | "새 데이터 없음" 토스트 |
| 전체 성공 | — | 성공 토스트 + 목록 갱신 |
| 일부 실패 | — | 부분 성공 토스트 + 목록 갱신 |
| 전체 실패 | — | 실패 토스트 |
| 네트워크 없음 | — | "네트워크 연결을 확인해 주세요" 토스트 |
