## 0. 이 제품의 라이팅 미션 (다른 일정 도구와 다른 점)

이 제품의 카피는 "효율"이 아니라 **"솔직해도 괜찮다는 안심"** 을 판다(PRD §8.1).
핵심 사용자는 **P3 선택 참석자 우민지** — "내가 회피를 누르면 5명에게 폐를 끼친다"는 압박 때문에 거짓으로 "가능"을 누르는 사람이다. 카피의 성패는 *이 사람이 솔직하게 avoid/hard-no를 누르게 만드는가*에 달려 있다.

따라서 모든 문구는 아래 세 가지를 동시에 만족해야 한다.

1. **안심을 먼저 준다** — 부정 응답·불참 앞에서 죄책감·경고·압박을 주지 않는다.
2. **중립을 지킨다** — 강도·불참을 "거부"나 "부정"으로 번역하지 않는다. 감정어를 쓰지 않는다.
3. **비공개를 체감시킨다** — "내 응답은 안 보인다"를 과장 없이 지속적으로 인지시킨다(NFR-002).

## 1. 보이스 퍼스널리티

PM 보이스(명확·신뢰·배려·적정 친근)를 이 제품의 정서 과제에 맞춰 한 축 더한다.

| 키워드 | 설명 | 이 제품에서의 적용 |
|---|---|---|
| **명확한 (Clear)** | 복잡한 기능도 쉽고 간결하게 | 강도 4단계를 한눈에 읽히는 중립 어휘로 |
| **신뢰할 수 있는 (Reliable)** | 정확하고 일관된 언어로 안정감 | 비공개 고지를 과장 없이, 약속한 그대로 |
| **배려하는 (Considerate)** | 사용자 상황을 이해하고 다음 행동 안내 | 미응답·부분응답·불참에 압박 대신 선택지 제시 |
| **안심을 주는 (Reassuring)** ★ | 부담스러운 순간에 먼저 마음을 놓게 한다 | "안 돼도 회의는 진행돼요"를 첫 화면에서 |

### 톤 스펙트럼 (이 제품의 위치)

```
딱딱함  ──────●───────────  가벼움      (중간보다 약간 차분 쪽)
격식체  ───────────●──────  구어체      (-해요체, 친근하되 가볍지 않게)
무미건조 ──────────●──────  과한 친절    (담백하게. 느낌표·이모지 남발 금지)
```

전문적이되 차갑지 않게, 따뜻하되 호들갑스럽지 않게. **개인 프로파일 반영**: AI 톤·과한 병렬구조·감탄 남발을 피하고 담백한 문어체 기반의 -해요체로 쓴다.

## 2. 존댓말·어미 체계

- **전체 -해요체로 통일.** `-합니다`/`-하십시오`/`-됩니다` 혼용 금지.
  - ✗ `응답이 전달되었습니다` → ✓ `응답을 전달했어요`
- **능동태 기본.** 시스템이 아니라 사용자/행동 중심.
  - ✗ `링크가 만료되었습니다` → ✓ `이 링크는 더 이상 쓸 수 없어요`
- **버튼은 동사형 라벨.** 묘사·명령이 아니라 행동.
  - `응답 시작`, `응답 제출`, `이 시간으로 확정`, `링크 복사`
- **호칭**: 2인칭은 꼭 필요할 때만 "당신". 안심 카피("당신이 안 돼도…")처럼 *안심을 직접 건넬 때*만 쓰고, 일반 안내에선 주어를 생략한다. "귀하" 금지.
- **느낌표·이모지**: 시스템 아이콘(🔒 ⓘ) 외 장식 이모지·연속 느낌표 금지. 완료 화면도 담백하게.

## 3. ★ 강도 어휘 사전 (이 제품의 심장)

강도 라벨은 가치판단 없는 **중립 척도 어휘**로 통일한다. "긍정 ← 중립 → 덜 선호"로 읽히되, 부정 끝이 "거부/싫음/안 됨"으로 읽히지 않게 한다(conventions "회피는 거부가 아님").

### 3.1 데모 4단계 확정 라벨

| id | 확정 라벨 | polarity | 읽히는 의미 | 왜 이 단어인가 |
|----|----------|----------|-----------|--------------|
| `prefer` | **선호** | + | 가장 좋은 시간 | 짧고 명확. "최선"·"강력추천"은 과함 |
| `ok` | **가능** | 0 | 무리 없이 됨 | "괜찮음"보다 객관적·중립 |
| `avoid` | **가급적 회피** | − | 되도록 피하고 싶음 | "회피"는 행동 묘사(중립). "싫음"·"불편"(감정어) 금지 |
| `hard-no` | **불가** | − | 그 시간은 안 됨 | "절대 불가"의 단정·강도 제거. "불가능"보다 짧고 덜 단정 |

> ★ `avoid` 라벨 결정의 핵심: 척 보면 "가급적 회피"는 길지만, 짧게 줄이면("회피") 차가워지고 "피함"은 어색하다. **"가급적 회피"** 가 강제성 없이 "되도록 안 했으면"을 정확히 전달한다. 단독 "회피"는 칩 공간이 좁을 때만 축약 허용(aria-label은 전체 사용).

### 3.2 강도 어휘 — 권장 / 금지 대조표

| 단계 | ✓ 권장 (중립) | ✗ 금지 (감정·단정·경고) | 이유 |
|------|--------------|----------------------|------|
| + | 선호 | 강력 추천 / 최선 / 완전 좋음 | 과장·호들갑 |
| 0 | 가능 | 그럭저럭 / 어쩔 수 없이 가능 | 부정 뉘앙스 주입 |
| − (soft) | 가급적 회피 / 되도록 피함 | 싫음 / 불편 / 별로 / 꺼림 | 감정어 — 솔직함 억제 |
| − (hard) | 불가 | 절대 불가 / 불가능 / 안 됨 / 거부 | 단정·거부 프레임 |

> 단계 수가 3↔4로 바뀌어도 이 사전을 척도 배열처럼 쓴다. 3단계 전환 시 `avoid`만 빼고 나머지 라벨은 그대로 재사용(선호/가능/불가).

### 3.3 강도 관련 보조 문구 원칙

- 부정 강도 칩 옆/선택 후에 **"정말요?" 류 재확인·경고 카피를 절대 붙이지 않는다.** 다른 칩과 동일하게 무덤덤하게 반영.
- aria-label은 행동을 중립 서술: `"이 시간 가급적 회피로 응답"`, `"이 시간 불가로 응답"`. ("불가능으로 표시" 같은 단정·경고 어휘 금지.)

## 4. ★ 안심 / 비공개 카피 원칙

이 둘은 제품의 차별점이자 우민지 Pain의 직접 해소 장치다. 카피 강도를 신중히 조절한다.

### 4.1 안심(Reassurance) 카피

- **빠져도 된다는 사실을 단정적으로, 그러나 가볍게.** "당신이 안 돼도 회의는 진행돼요"는 *권리 고지*이지 위로가 아니다 — 과한 공감("힘드시죠")·생색("배려해요")을 붙이지 않는다.
- **솔직함을 허락하는 한 줄을 함께.** "솔직하게 답해도 괜찮아요"로 행동을 직접 허가한다.
- 선택 참석자(`optional`)에게 강조, 필수 참석자(`required`)에겐 생략하거나 강도 안내로 대체.

### 4.2 비공개(Privacy) 카피

- **사실만, 과장 없이.** "다른 참석자에게 보이지 않아요"는 검증 가능한 사실로 쓴다. "완벽하게 익명"·"절대 안전" 같은 과대 보증 금지(신뢰 훼손 위험).
- **지속 노출용은 짧게.** 상주 배너·하단 바는 "이 응답은 비공개예요" / "🔒 비공개"처럼 최소 단위로(시각 방해 최소, 디자인 §2.4).
- **주최자도 안다는 점은 정직하게.** 완전 비공개가 아니라 "집계로만" 보인다 — 주최자 화면엔 "집계로만 표시돼요"로 정확히 고지(과대 약속 금지).

### 4.3 안심·비공개 카피 강도 스펙트럼

```
약함 ─────────────────────────── 강함
"비공개로 처리돼요"   "다른 참석자에게 보이지 않아요"   "누구도 볼 수 없어요"(✗과장)
                    └ 권장: 구체적·검증 가능한 사실 위치
```

## 5. 금지 표현 목록 (이 제품 특화 + 공통)

### 5.1 ★ 정서 가드레일 — 이 제품에서 특히 금지 (conventions 직속)

| 금지 표현/패턴 | 이유 | 대체 |
|---|---|---|
| `정말 회피하시겠어요?` / 부정 강도 재확인 | 죄책감·압박 유발(우민지 억제) | 재확인 없이 그대로 반영 |
| `거부` / `반대` / `안 됨` (강도 맥락) | 부정·거부 프레임 | `불가` / `가급적 회피` |
| `싫음` / `불편` / `별로` | 감정어 — 솔직함 억제 | `가급적 회피` |
| `아직 응답 안 하셨어요!` (독촉형) | 죄책감·압박 | `아직 응답 전이에요` (중립 사실) |
| `필수 인원에게 폐가 될 수 있어요` | 압박·죄책감 | 안내하지 않음 (해당 카피 자체 배제) |
| `위험` / `경고` / `주의!` + 느낌표 | 경고 정서(빨강 카피 등가물) | 중립 안내문 |
| `완벽 익명` / `절대 안전` | 과대 보증 | `다른 참석자에게 보이지 않아요` |

### 5.2 공통 금지 표현 (PM 가이드 승계)

| 금지 표현 | 이유 | 대체 |
|---|---|---|
| `~하십시오` | 권위적 | `~해 주세요` |
| `~되었습니다` | 수동태 | `~했어요` |
| `귀하` | 격식 과함 | 주어 생략 |
| `오류가 발생하였습니다` | 모호·불친절 | 구체 상황 + 다음 행동 |
| `정상적으로` / `성공적으로` | 불필요한 부사 | 삭제 |
| `~의 경우` / `본 서비스` | 번역투 | `~할 때` / `이 서비스` |
| `클릭하세요` | 디바이스 종속 | `선택해 주세요` / `눌러 주세요` |

## 6. 컴포넌트별 라이팅 규칙

- **[버튼]**: 동사형 2~8글자. `응답 시작` `응답 제출` `이 시간으로 확정` `링크 복사`. 취소는 `취소` 고정.
- **[빈상태]**: "왜 비었는지 + 무엇을 하면 되는지". 단, 미응답·무응답에 죄책감 금지.
- **[에러]**: "무엇이 + 다음 행동". 시스템 에러도 황토 톤과 일관되게 *부드럽게*(빨강 카피 정서 배제). 사용자 탓 금지.
- **[알림/토스트]**: 담백하게. 감탄·이모지 금지. `응답을 전달했어요`.
- **[레이블]**: 명사·짧게. 중립.
- **[플레이스홀더]**: 예시·형식 안내. `입력하세요` 단독 금지.

## 7. 검수 체크리스트 (모든 문구가 통과해야 함)

- [ ] 부정 강도/불참을 "거부·부정"으로 다루지 않았는가 (conventions 1순위)
- [ ] 감정어(싫음·불편·별로)를 쓰지 않았는가
- [ ] 죄책감·압박·경고·독촉 뉘앙스가 없는가
- [ ] 안심을 먼저 주는가 (부담스러운 순간에)
- [ ] 비공개를 과장 없이 정확히 고지했는가 (집계 노출 정직)
- [ ] -해요체·능동태로 일관됐는가
- [ ] 단계 수 가변(3↔4)에 라벨이 척도 배열처럼 대응되는가
- [ ] 버튼이 동사형이고 디바이스 종속 어휘가 없는가
