## 부록 A — 확정 라벨 요약 (Engineer 주입용)

`IntensityScale` 데모 4단계 `label` 필드 확정값:

```
prefer  → "선호"
ok      → "가능"
avoid   → "가급적 회피"
hard-no → "불가"
```

3단계 전환 시: `avoid` 제거, 나머지 라벨 그대로 재사용("선호"/"가능"/"불가").

aria-label 패턴: `"이 시간 {label}로 응답"` (척도 배열에서 자동 조합).
