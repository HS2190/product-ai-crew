## 공통 기능 명세

### F-APP-SRCH-001. 검색 실행

- **트리거 1**: 검색 버튼/아이콘 탭 (각 안별 위치 상이)
- **트리거 2**: 키보드 [완료]/[검색] 키 (모든 옵션 공통 지원)
- **동작**: 입력 텍스트로 작업 목록 필터링 실행
- **결과**: 필터링된 작업 목록 표시, 최근 검색 드롭다운 닫힘
- **예외 처리**
  - 검색어 0자 → 검색 버튼 Disabled, 실행 불가
  - 공백만 입력 → Disabled 유지
  - 결과 0건 → 기존 Empty State 처리
  - 네트워크 오류 → 기존 에러 처리

---

### F-APP-SRCH-002. 검색 버튼 활성/비활성 전환

- **대상**: A안([검색] 텍스트 버튼), B안(🔍 아이콘 버튼)
- **트리거**: 검색 필드 텍스트 변경
- **동작**
  - 0자 → Disabled (Gray, 탭 불가)
  - 1자 이상 → Enabled (Brand Blue, 탭 가능)
- **결과**: 버튼 색상 즉시 전환

---

### F-APP-SRCH-003. 입력 텍스트 클리어 (✕ 버튼)

- **트리거**: [✕] 버튼 탭 (기존 기능, 변경 없음)
- **동작**: 입력 텍스트 전체 삭제, 커서 필드 유지
- **결과**: Placeholder 재표시, 검색 버튼 Disabled 전환, 최근 검색 드롭다운 표시
- **표시 조건**: 텍스트 1자 이상 입력 시에만 표시

---

### F-APP-SRCH-004. 최근 검색 드롭다운 표시

- **트리거**: 검색 필드 포커스
- **동작**: Dropdown_Search_menu 표시 (최근 순, 최대 5개)
- **예외**: 최근 검색어 없음 → Empty State 표시

---

### F-APP-SRCH-005. 최근 검색어 선택

- **트리거**: 최근 검색 목록 항목 탭
- **동작**: 해당 검색어 필드에 입력 + 즉시 검색 실행
- **결과**: 검색 결과 목록 표시

---

### F-APP-SRCH-006. 최근 검색어 개별 삭제

- **트리거**: 검색 항목 [✕] 삭제 버튼 탭 (기존 기능, 변경 없음)
- **동작**: 해당 항목만 목록에서 제거
- **결과**: 목록 즉시 업데이트
