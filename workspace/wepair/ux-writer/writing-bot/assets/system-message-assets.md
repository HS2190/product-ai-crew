## 템플릿 패턴 모음

신규 문구 작성 시 아래 패턴을 우선 적용하고, 없는 경우에만 새로 작성.

### 토스트
```
성공  →  {대상}을 {동사}했어요.
재시도  →  {동작}하지 못했어요. 다시 시도해 주세요.
```

### 에러
```
입력 오류  →  {내용}이 일치하지 않아요. {해결 방법}해 주세요.
시간 초과  →  {항목} 시간이 지났어요. {해결 방법}해 주세요.
권한 부족  →  {기능}하지 못했어요. {해결 방법}해 주세요.
```

### 안내
```
입력 요청  →  {항목}을 입력해 주세요.
동의 요청  →  {약관명}에 동의해 주세요.
권한 요청  →  {기능}을 위해 {권한명}이 필요해요. ({설정 경로})
이동 안내  →  {대상}을 {목적지}으로 이동해요.
```

### 빈상태
```
기본  →  아직 {항목명}이 없어요.
유도  →  아직 {항목명}이 없어요. {행동}해 보세요.
상태  →  {조건}된 {항목명}이 없어요.
```

### 알림 (파괴적 액션)
```
제목  →  {동작명}  (명사형)
본문  →  {영향 설명}이에요. {경고 내용}해요. {동작}할까요?
버튼  →  취소  |  {동작명}
```

## 🔴 1순위 — 토스트 (Toast)

### 작성 원칙 요약
- `{대상}을 {동사}했어요.` 능동형 단문으로 통일
- 15자 이내 권장. `~가 되었습니다` 수동형 전면 금지
- `정상적으로`, `성공적으로` 삭제. 완료 사실만 서술

| 금지 | 대체 |
|------|------|
| ~가 되었습니다 | ~을 ~했어요 |
| ~이 완료되었습니다 | ~을 완료했어요 |
| 정상적으로 처리되었습니다 | 처리했어요 |
| 작업사진 (붙여쓰기) | 작업 사진 |
| 결제링크 (붙여쓰기) | 결제 링크 |

## 🔴 1순위 — 에러 (Error Message)

### 작성 원칙 요약
- 원인 + 해결 방법을 반드시 포함
- 사용자를 탓하는 표현 금지. 시스템/상황 중심으로 서술
- `-않아요`, `-없어요`, `-수 없어요` 해요체 통일

| 금지 | 대체 |
|------|------|
| ~않습니다 | ~않아요 |
| ~불가능합니다 | ~할 수 없어요 |
| 잘못된 입력입니다 | {항목} 형식을 확인해 주세요 |
| 확인해주세요 (붙여쓰기) | 확인해 주세요 |
| 불가능 합니다 (띄어쓰기) | 할 수 없어요 |

### 에셋 목록

| 에셋 ID | 상황 | 확정 문구 | 비고 |
|--------|------|---------|------|
| ERROR-001 | 로그인 정보 불일치 | 로그인 정보가 일치하지 않아요. 다시 확인해 주세요. | |
| ERROR-002 | 인증 정보 입력 시간 초과 | 인증 정보 입력 시간이 지났어요. 인증번호를 다시 발송하고 입력해 주세요. | |
| ERROR-003 | 업로드 파일 없음 | 업로드된 파일이 없어요. | 다음 행동 안내 추가 검토 필요 |
| ERROR-004 | 결제 취소 기간 경과 | 취소 가능일이 지나 직접 취소할 수 없어요. 고객센터(1660-4945)로 문의해 주세요. | |

### 템플릿 패턴

```
입력 오류  →  {내용}이 일치하지 않아요. {해결 방법}해 주세요.
시간 초과  →  {항목} 시간이 지났어요. {해결 방법}해 주세요.
기간 경과  →  {조건}이 지나 {동작}할 수 없어요. {연락처}로 문의해 주세요.
파일 오류  →  {파일 상태}예요. {해결 방법}해 주세요.
```

> 에러 에셋 4건 (수정 4건, 유지 0건)

## 🟠 2순위 — 안내 (Guidance)

### 작성 원칙 요약
- 사용자 행동 중심으로 서술. 시스템 주어 생략
- `해 주세요` 띄어쓰기 필수 (보조 동사 `주다`는 앞말과 띄어 씀)
- `~의 경우`, `입력하신` 등 번역투·높임말 과용 제거

| 금지 | 대체 |
|------|------|
| ~의 경우 | ~하면, ~할 때 |
| 입력하신 | 입력한 |
| ~해주세요 (붙여쓰기) | ~해 주세요 |
| 회원가입을 위한 필수 약관 | 필수 약관 |
| 위치해주세요 | 맞춰 주세요 |

### 에셋 목록

| 에셋 ID | 상황 | 확정 문구 | 비고 |

| GUIDE-002 | 약관 동의 요청 | 필수 약관에 모두 동의해 주세요. | |
| GUIDE-003 | 아이디 분실 안내 | 아이디를 잊으셨나요? 고객센터(1660-4945)로 문의해 주세요. | |

| GUIDE-005 | 차주 연락처 입력 요청 | 차주 연락처를 입력해 주세요. | |
| GUIDE-006 | 결제 취소 사유 입력 요청 | 결제 취소 사유를 입력해 주세요. | |

### 템플릿 패턴

```
입력 요청  →  {항목}을 입력해 주세요.
동의 요청  →  {약관명}에 모두 동의해 주세요.
```
