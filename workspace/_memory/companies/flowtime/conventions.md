# flowtime 컨벤션

> 이 회사의 톤·디자인 규칙·제약. 프로젝트마다 반복되는 회사 고유 맥락만 담는다.
> 새 회사는 이 `_template/` 폴더를 복사해 `companies/flowtime/`를 만들고 `flowtime`을 실제 이름으로 바꾼다.

## 브랜드·톤

- (이 회사의 보이스·톤앤매너, 호칭, 존댓말 체계 등)
- **"회피는 거부가 아님"** — 부정 강도(가급적 회피 등)나 불참을 거부·부정으로 다루지 않는다. 중립 어휘를 쓰고("싫음" 등 감정어 금지), 죄책감·압박·경고 카피를 배제한다. 안심을 먼저 준다. *근거: 선택 참석자의 솔직한 응답 보호.* (출처: timefit-flowtime, 2026-06-29)

## 디자인 시스템·컴포넌트 규칙

- (색·타이포·간격 토큰, 재사용 컴포넌트 규칙, 패턴 합의)
- **부정 강도·에러를 빨강이 아닌 황토(`#B5852A`)로 통일**하고, 빨강을 팔레트에서 배제한다. 강도는 채도 빼기 + 형태/라벨로 구분한다. *근거: "회피는 거부가 아님"의 시각 번역, 색약 접근성.* (출처: timefit-flowtime, 2026-06-29)
- **의미색 칩의 라벨 전경(fg)은 배경 대비 AA(≥4.5:1)를 *실측*으로 보장**하고, soft/hard(강·약) 강도 구분은 fg 명도가 아니라 **형태 + 테두리 채도** 채널로 분리한다. *근거: 형태 단서는 색약 1차 방어선일 뿐, 라벨 텍스트가 AA 미달이면 저시력 사용자에게 안 읽힌다 — 형태가 대비 미달을 면제하지 않는다. 가독성과 강도 구분을 같은 fg 토큰에 얹으면 충돌한다.* (출처: timefit-flowtime, 2026-06-30)
