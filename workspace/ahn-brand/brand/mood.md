# mood — ahn. (안현서 개인 브랜딩 사이트)

> 출처: brand-core.md (본인 답변 기반) + 콘셉트 A2 "Built to last" 피드백. critique-brand-consistency의 기준 파일.

## 성격 키워드

**Trustworthy · Bold · Minimal · Built to last**

- 믿을 수 있는 — 부풀리지 않고, 근거를 보여준다
- 과감한 — 큰 타이포 하나로 말한다. 망설이는 크기·여러 강조를 쓰지 않는다
- 미니멀 — 요소를 더하지 않고 뺀다. 여백이 구조다
- 오래 쓰이는 — 유행 장식이 아니라 오래 가는 형식(그리드, 선, 활자)

## 시각 방향

- 흑백 위주 + 포인트 색 **하나**(코발트). 포인트 색은 마침표·상태 점·링크 같은 아주 작은 면적에만
- 거대한 영문 디스플레이 타이포가 화면의 주인공. 이미지가 아니라 활자가 이미지 역할
- 1.5px 검정 가로 선으로 구획. 박스·카드·그림자로 나누지 않는다
- 12컬럼 그리드에 엄격하게 정렬. 비어 있는 컬럼을 채우지 않는다
- 정보는 라벨(STATUS · MISSING · DECISION · PROOF)과 짧은 값으로 압축

## 레이아웃 문법 — "사람의 사양서" (A3, 2026-10-25 추가)

A2가 "너무 단순하고 재미없다"는 피드백 → 인더스트리얼 스펙 시트 × 스위스 모노 레퍼런스로 구조를 잡는다. 재미는 장식이 아니라 **정보를 사양서처럼 다루는 장치**에서 나온다.

- 상단 사양 칸(Unit · Discipline · Since · Team size · Rule · Status)
- 보이는 그리드 세로선 + 교차점 십자(+) 표시
- 모델 번호가 붙은 데이터시트(CRW-01 · IRS-02 · GTM-03) — 크기를 달리해 같은 카드 반복을 피함
- 도식: 원 다이얼(Screen → Flow → System, 중심은 근거), 단계 흐름 + 검수 게이트(◆)
- 거대한 숫자·로마숫자, 측정 눈금자(1눈금 = 1년), 기간 막대
- 바코드·Ref 번호, 떼어 가는 라벨(✂)과 도장 "NO CLAIM WITHOUT PROOF"
- 덱과 구분: 덱은 웜 페이퍼 + 번트 오렌지 + 도면 장식, 사이트는 쿨 오프화이트 + 코발트 + 사양서·라벨 언어

## Do

- 섹션마다 큰 제목 하나, 나머지는 작게 — 크기 대비를 극단적으로
- 근거 태그로 모든 숫자·주장에 출처 표시 (`관찰` `출처` `본인`)
- 작업은 "없던 것 → 판단 → 근거" 순서
- 과정·판단이 완성 화면보다 먼저

## Don't

- 일러스트, 사물 그림, 소품, 스티커, 손글씨 장식 (콘셉트 A 가게 시안 반려 — "내 스타일 아님")
- 손글씨 메모 · 손그림 동그라미 · 가리키는 화살표(↑ ↓ ↗) 주석 레이어 전부 금지 (2026-10-25 v2에서 사용자가 "다 지워줘"). 문장 안 화살표도 말로 바꾼다: "5H → 2H" → "5시간에서 2시간"
- 그라데이션, 큰 그림자, 둥근 카드 반복, 글래스
- 포인트 색을 넓은 면에 칠하기, 두 번째 포인트 색 추가
- 왼쪽 세로선 + 박스로 강조하기 (AI 티 패턴)
- 성과 수치를 근거 없이 크게 쓰기
- 범용 PDF 덱 문법(웜 페이퍼 #F2EFE9 + 번트 오렌지 #D2521E, 도면 장식) 재사용
