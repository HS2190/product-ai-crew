# ahn-brand 프로젝트 컨텍스트 (오케스트레이터 작성, 2026-10-25)

에이전트는 대화 이력을 공유하지 않으므로, 이 파일이 지금까지의 맥락 전부다.

## 1. 무엇을 하려는가

안현서(프로덕트 디자이너)의 현재 웹 포트폴리오(https://ahn-hyeonseo.vercel.app, repo HS2190/ahn, Astro, Vercel 자동 배포)를 **개인 브랜딩 사이트**로 전환한다. 사용자 표현: "뭔가 더 개인 브랜딩 사이트 느낌처럼 만들고 싶다." 지원 마감용이 아니며 일정 제약 없음.

## 2. 사용자 확정 사항 (반드시 지킬 것)

1. 포지셔닝 = **"직접 만드는 디자이너"** — AI 에이전트 팀, 디자인 시스템, AI 도구를 직접 기획·디자인·개발·배포까지 하는 사람. 대안이었던 "공정을 아는 디자이너"(제조 경력 전면)는 기각됨. 제조 현장 7년은 이야기 소재로는 쓸 수 있음
2. 범용 PDF 덱(웜 페이퍼 #F2EFE9 + 번트 오렌지 #D2521E, 도면 문법)과 **통일하지 않음** — 사이트는 별도 아이덴티티
3. **얼굴 사진 미사용** — 일러스트 또는 손글씨로 사람의 존재감을 대체
4. **노트/글 섹션 제외**
5. 일정 없음

## 3. 오케스트레이터 진단 — 지금 사이트가 "포트폴리오"로만 읽히는 이유

1. 정보가 이력서 순서(히어로 → 케이스 6 → 일하는 방식 → 경력 → 연락처). 스타일을 바꿔도 "잘 정리된 이력서"로 읽힘. 사람보다 작업 목록이 먼저 보임
2. 관점이 안 보임. "From screens to systems"는 하는 일을 말하지만 무엇을 믿는지, 남과 어떻게 다르게 보는지는 말하지 않음
3. 고유한 시각 장치가 없음. 시안 7종 모두 레퍼런스 스타일의 차용

## 5. 과거 브랜드 판단과의 긴장 (PM이 직접 풀어야 함)

이전 PDF 덱 프로젝트(workspace/portfolio/pm/brand-direction.md, 2026-07)는 "증거 우선 · 구조 설계 · AI 판단 설계(조건부 3순위)"를 축으로 삼고 **"도구 자랑 서사 금지"**, "AI 팀의 판단을 구조화했고 모든 판단은 사람이 한다" 프레임을 정했다. 이번 포지셔닝 "직접 만드는 디자이너"는 만든 것(도구)을 전면에 내세운다. 둘이 충돌하지 않게 — 무엇을 만들었는지가 아니라 **왜 만들었고 만들면서 무엇을 판단했는지**로 서사를 세울지 등 — PM이 판단하고 근거를 남길 것.
