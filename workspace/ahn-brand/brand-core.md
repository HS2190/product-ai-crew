## 3. 브랜드를 꿰는 실 — "오래 쓰이는 것"

취향(오래 쓰이는 그릇·물건)과 가장 아끼는 작업(회사가 바뀌어도 계속 쓰는 크루)이 같은 말을 한다.
**한 번 쓰고 버릴 화면이 아니라, 오래 쓰이는 것을 만든다.** 디자인 시스템, 작업 체계, 기준 — 전부 계속 쓰이는 것.
보조 문장: "오래 쓰이는 것을 만듭니다."

## 4. 믿는 것

1. **낱장이 아니라 흐름부터 봅니다.** 한 단계가 막히면 뒤가 전부 밀리니까.
2. **근거 없는 말은 하지 않습니다.** 실제와 다르면 끝까지 고치고, 성과를 디자인만의 몫이라 하지 않습니다.
3. **없으면 만듭니다.** 기획자가 없으면 기획 문서를, 시스템이 없으면 시스템을. 직접 고민한 다음에.
4. **쓰는 사람 자리에서 봅니다.** 불편한 화면을 오래 써 본 사람이라서.

## 5. 사이트 규칙

| 성과 부풀리기 | 모든 수치·주장에 **근거 태그**(실측 / 관찰 / 출처) + 기여 범위 명시 |
| 겉만 꾸미기 | 완성 화면보다 과정·판단이 먼저. 장식은 콘텐츠와 1:1로 묶인 것만 |
| 도구에 기대기 | AI·도구는 "어디서 직접 판단했나"로 서술 |

## 6. 시그니처 장치

- **근거 태그** — 숫자·주장 옆 `실측` `관찰` `출처`
- **손글씨 "이거 근거가 뭐예요?"** — 본인이 실제로 하는 말
- **물건 태그(빈티지 가격표)** — 만든 것마다 제작 연도 · 쓰임 · "지금도 쓰는 중"

## 7. 콘셉트 3안

- **A. 오래 쓰는 물건 가게 (채택)** — 사이트 = 현서가 만든 "오래 쓰이는 것"을 진열한 작은 가게. 만든 것마다 물건 태그, 크루가 가장 오래 쓴 물건으로 맨 앞. 회사 작업은 "주문 제작". 따뜻한 종이·도자기 톤, 사물 일러스트, 손글씨 태그. 근거 태그로 단단함을 붙잡음
- B. 공정 라인 — 위에서 아래로 이어지는 하나의 공정 라인. 덱의 도면 문법과 겹칠 위험
- C. 교정지 — 부풀린 표현에 줄을 긋고 고친 흔적. 차갑게 읽힐 위험 → A의 시그니처(근거 태그)로 흡수
