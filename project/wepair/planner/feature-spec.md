# 기능 명세 — AOS 자동/수동 입고 연동

## 기능 1 — 자동 반영 (앱 실행 시)

| 기능명 | 설명 | 조건 | 예외 처리 | 우선순위 |
|---|---|---|---|---|
| AIAOS 폴더 스캔 | 앱 포그라운드 진입 시 AIAOS전송/ 폴더 자동 스캔 | 앱 실행 or 백그라운드→포그라운드 복귀 | 폴더 없음 → 스킵 (무음) | 필수 |
| 폴더명 파싱 | 폴더명 "차량번호_차종" 패턴 파싱 | 언더스코어(_) 구분 필수 | 형식 불일치 → 해당 폴더 스킵 | 필수 |
| 차량번호 추출 | 폴더명 언더스코어 앞부분 추출 | 예: 12가1234_쏘렌토 → 12가1234 | 추출 실패 → 스킵 | 필수 |
| 차종명 정규화 | 언더스코어 뒷부분 추출 후 표준 차종명 매핑 | 쏘렌토 / 쏘렌토 MQ4 / 기아 쏘렌토 → 쏘렌토 | 매핑 실패 → 원본 문자열 그대로 사용 [확인 필요] | 필수 |
| 중복 체크 | 차량번호 기준 위페어 DB 내 기존 입고 건 조회 | 동일 차량번호 존재 시 스킵 | 중복 감지 → 스킵 (알림 없음) | 필수 |
| 입고등록 API 호출 | 파싱된 데이터로 위페어 입고등록 API 호출 | 신규 차량번호만 처리 | API 오류 → 실패 토스트 + 수동 연동 유도 | 필수 |
| 대표사진 업로드 | AIAOS전송/ 폴더 내 첫 번째 사진 1장 업로드 | 사진 파일 존재 시 | 사진 없음 → 플레이스홀더로 등록 | 필수 |
| 초기사진 업로드 | AIAOS전송/ 폴더 내 나머지 전체 사진 업로드 | 대표사진 업로드 성공 후 | 업로드 실패 → 입고 등록 유지, 사진 누락 표시 | 권장 |
| 자동 반영 피드백 | 등록 완료 후 토스트 표시 | 1건 이상 신규 등록 완료 시 | 0건 → 토스트 없음 | 필수 |

## 기능 2 — 수동 연동 (AOS 불러오기 버튼)

| 기능명 | 설명 | 조건 | 예외 처리 | 우선순위 |
|---|---|---|---|---|
| 버튼 탭 감지 | 작업목록 내 Btn_AOS_Import 탭 인식 | 기본(Idle) 상태에서만 활성 | 연동 중 탭 → 무반응 | 필수 |
| 버튼 로딩 전환 | 탭 즉시 스피너 상태로 전환 | 탭 이벤트 발생 시 | — | 필수 |
| AIAOS 폴더 스캔 | 자동 반영과 동일한 스캔 로직 수행 | 버튼 탭 후 | 폴더 없음 → 안내 토스트 | 필수 |
| 신규 데이터 없음 처리 | 모든 폴더가 이미 등록된 경우 | 스캔 결과 신규 0건 | "새로운 입고 데이터가 없습니다" 토스트 | 필수 |
| 연동 완료 처리 | 1건 이상 등록 성공 | API 응답 성공 | "N건 등록 완료" 토스트 | 필수 |
| 연동 실패 처리 | API 호출 실패 또는 네트워크 오류 | 예외 발생 시 | "연동 실패. 다시 시도해주세요" 토스트 + 버튼 복귀 | 필수 |
| 버튼 원상복귀 | 성공/실패 모두 로딩 → 기본 상태 복귀 | 처리 완료 후 | — | 필수 |

## 공통 예외 처리 기준

| 케이스 | 처리 방식 |
|---|---|
| AIAOS전송/ 폴더 없음 | 수동: "AOS 데이터 폴더를 찾을 수 없습니다" 토스트 / 자동: 무음 스킵 |
| 폴더명 형식 불일치 | 해당 폴더 스킵 후 나머지 계속 처리 |
| 이미 등록된 차량번호 | 중복 감지 → 스킵 (사용자 노출 없음) |
| 네트워크 오류 | 실패 토스트 표시, 데이터 유실 없음 |
| 사진 업로드 실패 | 입고 등록 유지, 사진만 누락 상태로 표시 [확인 필요] |
| 앱 강제 종료 (처리 중) | 다음 앱 실행 시 미처리 데이터 재시도 [확인 필요] |
