## 3. 신규 요소 정의

### 3-1. 수동 AOS 불러오기 버튼 (니즈 2)

#### 위치
- `Row_Filter_Tools` 영역 내 정렬 버튼(↕ 입고일)과 검색창 사이
- 또는 검색창 우측 끝에 아이콘 버튼으로 배치 (검색창 너비 축소)

> **권장 배치안:**
> `[↕ 입고일]` · `[AOS 불러오기 ↓]` · `[🔍 검색창 ✕]`
> 검색창 너비: 기존 245px → 180px로 조정, 불러오기 버튼 너비: 약 60px (아이콘+레이블 생략형)

#### 컴포넌트 명세

| 항목 | 내용 |
|---|---|
| 컴포넌트명 | Btn_AOS_Sync |
| 형태 | 아이콘 버튼 (outlined, 소형) |
| 레이블 | 없음 (아이콘만) 또는 "AOS" 텍스트 + 동기화 아이콘 |
| 아이콘 | sync / cloud_download 계열 |
| 크기 | 높이 46px (Row_Filter_Tools 동일), 너비 46px |
| 기본 상태 | 아이콘 + 테두리, 비활성 배경 |
| 탭 가능 여부 | 연동 진행 중에는 비활성 (disabled) |

#### 상태 정의

| 상태 | 아이콘 | 배경 | 비고 |
|---|---|---|---|
| 기본 (Default) | sync 아이콘 | 흰색 / 회색 테두리 | 탭 가능 |
| 로딩 (Loading) | 스피너 (회전 애니메이션) | 흰색 | 탭 불가 (disabled) |
| 완료 (Success) | check 아이콘 | 흰색 | 2초 후 기본 상태 복귀 |
| 실패 (Error) | sync 아이콘 (빨간색) | 흰색 | 탭하면 재시도 |

### 3-2. 자동 반영 피드백 UI (니즈 1)

#### 3-2-1. 토스트 메시지

| 상태 | 문구 | 지속 시간 |
|---|---|---|
| 자동 반영 성공 (1건) | `1건의 입고 데이터를 불러왔어요` | 3초 |
| 자동 반영 성공 (N건) | `N건의 입고 데이터를 불러왔어요` | 3초 |
| 자동 반영 실패 | `AOS 연동에 실패했어요. 수동으로 불러와 주세요` | 4초 |
| 수동 성공 | `N건 입고를 불러왔어요` | 3초 |
| 수동 — 새 데이터 없음 | `새로 불러올 입고 데이터가 없어요` | 3초 |
| 수동 — 권한 없음 | `AOS 폴더에 접근할 수 없어요. 권한을 확인해 주세요` | 4초 |
| 수동 — 네트워크 오류 | `네트워크 연결을 확인해 주세요` | 3초 |
| 수동 — 일부 실패 | `N건 중 M건 불러오기에 실패했어요` | 4초 |

- 위치: 하단 탭 바 위 16px
- 형태: 배경 #1A1A1A, 텍스트 흰색, 모서리 반경 8px, 좌우 패딩 16px

#### 3-2-2. AOS 연동 배지 (작업 카드 내)

자동 반영으로 생성된 작업 카드에는 기존 배지 영역 옆에 **"AOS"** 구분 배지를 추가한다.

| 항목 | 내용 |
|---|---|
| 위치 | 카드 내 배지 Row 끝 또는 차량번호 옆 |
| 텍스트 | `AOS` |
| 배경색 | 브랜드 포인트 컬러 또는 구별되는 색 (예: #4A90D9) |
| 텍스트 색 | 흰색 |
| 높이 | 20px (소형 배지) |
| 우선순위 | 권장 |

## 5. 엣지 케이스

| 케이스 | 처리 방식 |
|---|---|
| AOS 폴더 자체가 없음 | 오류 없이 종료, 피드백 없음 |
| 폴더는 있으나 사진 없음 | 차량 정보만 등록, 대표사진 없는 카드 생성 |
| 동일 차량번호 중복 요청 | 해당 건 skip, 나머지 정상 처리 |
| 연동 중 앱 백그라운드 전환 | 완료 후 포그라운드 복귀 시 결과 토스트 표시 |
| 차종명 정규화 실패 | 원본 문자열 그대로 등록, 수동 수정 유도 없음 |
| 네트워크 없음 | "네트워크 연결 확인" 토스트, 버튼 기본 복귀 |

- 탭 구조 (작업중 / 작업완료) 유지
- 하단 탭 바 구조 유지
