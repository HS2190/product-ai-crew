# 화면 정의서 — SCR-MAIN-001 작업목록 변경 사항

## 1. 화면 개요

| 항목 | 내용 |
|---|---|
| 화면명 | SCR-MAIN-001 작업목록 (입고일 기준) |
| 목적 | AOS 자동/수동 연동 기능 추가에 따른 작업목록 화면 변경 정의 |
| 진입 경로 | 앱 실행 → 작업목록 탭 |
| 변경 범위 | Row_Filter_Tools 영역 내 AOS 불러오기 버튼 추가 / 피드백 UI 추가 |
| 우선순위 | 필수 |

[Row_Filter_Tools]

## 4. 상태별 화면 정의

### 4-1. 기본 상태 (Idle)
- Btn_AOS_Import 정상 표시
- 작업목록 기존과 동일하게 표시

### 4-2. 연동 중 상태 (Loading)
| 요소 | 처리 |
|---|---|
| Btn_AOS_Import | 로딩 스피너로 전환, 탭 비활성화 |
| 작업목록 | 기존 리스트 유지 (블로킹 없음) |
| 배너/오버레이 | 없음 (논블로킹 방식) |

### 4-3. 연동 완료 상태 (Success)
| 요소 | 처리 |
|---|---|
| Btn_AOS_Import | 기본 상태로 복귀 |
| 토스트 메시지 | "AOS에서 N건이 자동 등록되었습니다" (하단, 3초 후 사라짐) |
| 신규 카드 | 작업목록 상단에 삽입 (D-배지 또는 NEW 배지 표시) |
| 새로운 데이터 없음 | "새로운 입고 데이터가 없습니다" 토스트 |

### 4-4. 연동 실패 상태 (Error)
| 요소 | 처리 |
|---|---|
| Btn_AOS_Import | 기본 상태로 복귀 |
| 토스트 메시지 | "연동 실패. 다시 시도해주세요" (하단, 4초) |
| 색상 | 토스트 배경 #FF4D4F (에러 레드) |

### 4-5. 자동 반영 완료 (Auto Sync)
| 요소 | 처리 |
|---|---|
| 앱 진입 시 | 백그라운드 처리 (블로킹 없음) |
| 완료 후 | 토스트: "AOS에서 N건이 자동 등록되었습니다" |
| 작업목록 | 자동으로 업데이트됨 |

## 6. 엣지 케이스

| 케이스 | 화면 처리 |
