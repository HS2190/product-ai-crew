# 사용자 플로우 — AOS 자동 입고 연동

## AS-IS 흐름 (현재)

```
[사용자: 입고등록 진입]
        ↓
[앨범에서 사진 선택]
        ↓
[OCR 차량번호 인식] ─── 인식 실패 → [수동 입력]
        ↓
[차종 수기 입력]
        ↓
[입고등록 완료] → [작업목록 반영]
```

**문제**: AOS에서 이미 완료된 차량번호 인식·차종 확인·사진 촬영을 위페어에서 재수행

## TO-BE 흐름 1 — 앱 실행 시 자동 반영

```
[사용자: 위페어 앱 실행]
        ↓
[시스템: AIAOS전송/ 폴더 스캔]
        ↓
[신규 폴더 감지?] ─── 없음 → [작업목록 정상 표시 (변화 없음)]
        ↓ 있음
[폴더명 파싱: 차량번호_차종]
        ↓
[중복 차량번호 체크] ─── 중복 → [스킵 (알림 없음)]
        ↓ 신규
[위페어 입고등록 API 호출]
        ↓
[API 성공?] ─── 실패 → [실패 토스트 표시] → [수동 연동 유도 메시지]
        ↓ 성공
[대표사진 업로드 (첫 번째 1장)]
        ↓
[나머지 초기사진 업로드]
        ↓
[작업목록 자동 반영]
        ↓
[성공 피드백: 토스트 or 배지]
        예) "AOS에서 N건이 자동 등록되었습니다"
```

**트리거**: 앱 포그라운드 진입 시 (최초 실행 + 백그라운드→포그라운드 복귀)
**사용자 조작**: 없음 (완전 자동)

## TO-BE 흐름 2 — 수동 연동 (AOS 불러오기 버튼)

```
[작업목록 화면]
        ↓
[사용자: 'AOS 불러오기' 버튼 탭]
        ↓
[버튼 → 로딩 스피너 상태 전환]
        ↓
[시스템: AIAOS전송/ 폴더 스캔]
        ↓
[신규 폴더 감지?] ─── 없음 → ["새로운 입고 데이터가 없습니다" 토스트]
        ↓ 있음
[폴더명 파싱: 차량번호_차종]
        ↓
[중복 차량번호 체크] ─── 중복 항목 제외
        ↓ 신규만 처리
[위페어 입고등록 API 호출]
        ↓
[API 성공?]
  ├── 성공 → [사진 업로드] → [작업목록 반영] → ["N건 등록 완료" 토스트]
  └── 실패 → ["연동 실패. 다시 시도해주세요" 토스트] → [버튼 원상복귀]

[AOS 폴더 없음] → ["AOS 데이터 폴더를 찾을 수 없습니다" 토스트]
[네트워크 없음] → ["네트워크 연결을 확인해주세요" 토스트]
```

**예외 케이스**
| 케이스 | 처리 |
|---|---|
| AIAOS전송/ 폴더 자체 없음 | "AOS 데이터 폴더를 찾을 수 없습니다" 토스트 |
| 폴더명 파싱 실패 (형식 불일치) | 해당 폴더 스킵, 나머지 처리 계속 |
| 이미 등록된 차량번호 | 중복 감지 후 스킵 (별도 알림 없음) |
| 네트워크 오류 | 실패 토스트 → 버튼 원상복귀 |
| 사진 업로드 실패 | 입고 등록은 유지, 사진만 누락 표시 [확인 필요] |
| 연동 중 재탭 | 버튼 비활성화 (중복 호출 방지) |
