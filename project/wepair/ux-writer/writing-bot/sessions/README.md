# Sessions — 세션 파일 관리 안내

이 폴더는 UX Writing 봇과의 작업 세션 기록을 저장합니다.
누적된 세션 기록에서 반복 패턴을 발견하면 `docs/`로 원칙을 승격합니다.

---

## 세션 파일 생성 규칙

### 파일명 형식

```
YYYY-MM-DD.md
```

예시: `2026-04-29.md`, `2026-05-03.md`

- 하루에 여러 세션을 진행할 경우 동일 파일에 섹션을 추가합니다
- 파일은 날짜 기준으로 생성하며 소급 생성은 하지 않습니다

---

## 세션 파일 구조 템플릿

아래 템플릿을 복사해서 사용하세요.

```markdown
# YYYY-MM-DD 세션 기록

## 작업 개요
- 작업 유형: (전수조사 / 문구 검수 / 문구 생성 / 가이드 업데이트)
- 대상 화면: (화면명 또는 기능명)
- 요청자:

---

## 작업 내용

### 처리한 케이스
| 케이스 ID | 원문 | 수정안 | 적용 규칙 |
|---|---|---|---|
| CASE-XXX | | | |

### 새로 발견한 패턴
(이번 세션에서 새롭게 발견된 오류 패턴이나 규칙 후보를 기록합니다)

---

## 결정 사항
(이번 세션에서 확정된 표현, 예외 처리, 기준 변경 등을 기록합니다)

---

## 승격 후보
(같은 패턴이 3회 이상 반복되면 docs/ 승격을 검토합니다)

| 패턴 | 반복 횟수 | 승격 여부 |
|---|---|---|
| | | 검토 중 / 승격 완료 / 보류 |
```

---

## 원칙 승격 기준

세션 기록에서 동일한 패턴이 반복되면 `docs/`의 공식 원칙으로 승격합니다.

### 승격 트리거

> **같은 패턴이 3회 이상 반복될 경우** 승격을 검토합니다.

| 단계 | 기준 | 액션 |
|---|---|---|
| 1회 발견 | 세션 기록에 메모 | 세션 파일 작성 |
| 2회 반복 | 패턴 가능성 인지 | 세션 파일 승격 후보 표시 |
| 3회 이상 | 승격 검토 시작 | `docs/` 문서에 규칙 추가 |

### 승격 대상 문서

| 패턴 유형 | 승격 위치 |
|---|---|
| 어투·문체 규칙 | `docs/voice-and-tone.md` |
| 컴포넌트별 규칙 | `docs/component-rules.md` |
| 용어 표기 | `docs/glossary.md` |
| 특수 케이스 | `cases/index.md` + `cases/wepair-audit-cases.md` |

### 승격 절차

1. 세션 파일의 "승격 후보" 섹션에 기록
2. UX 라이터가 패턴을 확인하고 표준화 여부 결정
3. 해당 `docs/` 파일에 규칙 추가
4. 세션 파일 승격 상태를 "승격 완료"로 업데이트
