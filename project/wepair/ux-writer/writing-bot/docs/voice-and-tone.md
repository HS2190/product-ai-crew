# Voice & Tone — 위페어 파트너스

> 이 문서는 위페어 파트너스의 보이스 퍼스낼리티와 상황별 톤 적용 기준을 정의합니다.

---

## 1. 보이스 퍼스낼리티 키워드

위페어 파트너스의 언어는 4가지 키워드로 정의됩니다.

| 키워드 | 정의 | 한 줄 기준 |
|---|---|---|
| **명확한 (Clear)** | 복잡한 기능도 쉽고 간결하게 설명한다 | 사용자가 다음에 뭘 해야 할지 한 번에 알 수 있어야 한다 |
| **신뢰할 수 있는 (Reliable)** | 정확하고 일관된 언어로 안정감을 준다 | 같은 개념은 항상 같은 단어로 표현한다 |
| **배려하는 (Considerate)** | 사용자 상황을 이해하고 다음 행동을 안내한다 | 에러 상황에서도 사용자 편에서 말한다 |
| **적당히 친근한 (Warm but composed)** | 따뜻하되 가볍지 않은 어투를 유지한다 | 친근함과 전문성의 균형을 유지한다 |

---

## 2. 톤 스펙트럼

```
딱딱함 ──────────●──────── 가벼움
격식체 ─────────●─────────  구어체
차가움 ──────────────●──── 과도한 친절
```

**위치 해석:** 전문적이되 차갑지 않게, 친근하되 가볍지 않게.
중심보다 약간 구어체·친근함 쪽에 위치하지만, B2B 업무 툴로서 격식의 최소 기준은 유지한다.

## 3. 상황별 톤 적용 기준

### 에러 (Error)

사용자를 탓하지 않는다. 원인과 해결 방법을 함께 제공한다.

| 톤 방향 | 설명 |
|---|---|
| 중립적·사실적 | 무엇이 잘못됐는지 사실만 말한다 |
| 지시적 | 어떻게 하면 되는지 명확히 안내한다 |
| 과도한 사과 금지 | "죄송합니다" 반복 금지 |

```
❌ 잘못된 입력입니다.
❌ 오류가 발생하였습니다.
✅ 이메일 형식을 확인해 주세요.
✅ 아이디 또는 비밀번호를 확인해 주세요.
```

### 성공 (Success / Toast)

간결하고 능동적으로. 과도한 감탄 없이.

| 톤 방향 | 설명 |
|---|---|
| 능동적·긍정적 | 무엇을 완료했는지 사용자 행동으로 표현한다 |
| 간결 | 1문장 이내 |
| 과장 금지 | 느낌표, 이모지, "완벽해요!" 금지 |

```
❌ 비밀번호 재설정이 완료되었습니다!!! 🎉
❌ 귀하의 요청이 정상적으로 접수되었습니다.
✅ 비밀번호를 재설정했어요.
✅ 요청을 접수했어요.
```

### 안내 (Guide / Instruction)

다음 행동이 명확하게 보여야 한다.

| 톤 방향 | 설명 |
|---|---|
| 간결·직접적 | 불필요한 수식어 제거 |
| 행동 중심 | "~하면 됩니다"가 아닌 "~해 주세요" |
| 이유 제공 | 필요한 경우 왜 해야 하는지도 함께 |

```
❌ 회원가입을 위한 필수 약관에 모두 동의해주세요.
❌ 카메라를 사용할 수 있는 권한이 필요합니다.
✅ 필수 약관에 모두 동의해 주세요.
✅ 사진 촬영을 위해 카메라 접근 권한이 필요해요.
```

### 빈상태 (Empty State)

왜 비어있는지 + 무엇을 하면 채워지는지. 두 가지를 반드시 포함한다.

| 톤 방향 | 설명 |
|---|---|
| 공감적 | "아직"을 활용해 임시 상태임을 암시 |
| 행동 유도 | 다음 행동을 제안한다 |
| 단정 금지 | "-없습니다"로만 끝내지 않는다 |

```
❌ 데이터가 없습니다.
❌ 출고일 미지정
✅ 아직 등록된 항목이 없어요. 새 항목을 추가해 보세요.
✅ 출고일을 선택해 주세요.
```

## 4. DO / DON'T

### DO

- `-해요` 체로 통일한다
- 능동태를 기본으로 쓴다 (`저장했어요` / `삭제했어요`)
- 한 문장에 하나의 메시지만 담는다
- 에러 메시지에 해결 방법을 포함한다
- 빈상태에 다음 행동을 안내한다
- 버튼은 동작을 나타내는 동사로 쓴다 (`저장하기`, `다음으로`)

### DON'T

- `-합니다` / `-됩니다` / `-하십시오` 사용 금지
- 수동태 금지 (`~되었습니다`, `~이 완료되었습니다`)
- 번역투 금지 (`~의 경우`, `본 서비스`, `~을 통해`)
- 불필요한 부사 금지 (`정상적으로`, `성공적으로`)
- 사용자를 탓하는 표현 금지 (`잘못된`, `올바르지 않은`)
- 과도한 감탄 금지 (`!!!`, `🎉`, `완벽해요!`)
- 디바이스 종속 표현 금지 (`클릭하세요` → `선택해 주세요`)
