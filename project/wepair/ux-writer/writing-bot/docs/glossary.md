# Glossary — 용어 사전

> 위페어 파트너스 전수조사 결과를 기반으로 정의한 용어 기준입니다.
> 신규 화면 작업 시 이 문서를 우선 확인하세요.

---

## 금지어·권장어 목록

| 금지 표현 | 이유 | 권장 표현 |
|---|---|---|
| `~하십시오` | 딱딱하고 권위적 | `~해 주세요` |
| `~되었습니다` | 수동태, 어색함 | `~했어요` |
| `~됩니다` | 수동태 | `~돼요`, `~해요` |
| `~입니다` (알림·에러) | 딱딱한 격식체 | `~예요`, `~이에요` |
| `~없습니다` | 딱딱한 격식체 | `~없어요` |
| `~있습니다` | 딱딱한 격식체 | `~있어요` |
| `귀하` | 지나치게 격식체 | 주어 생략 또는 맥락 표현 |
| `정상적으로` | 불필요한 부사 | 삭제 |
| `성공적으로` | 불필요한 부사 | 삭제 |
| `~의 경우` | 번역투 | `~하면`, `~할 때` |
| `~을 통해` | 번역투 | `~로`, `~에서` |
| `~에 대한` | 번역투 | 생략 또는 재구성 |
| `~을 진행하다` | 번역투 | `~하다` |
| `본 서비스` / `본 페이지` | 번역투·딱딱함 | `이 서비스`, `이 페이지` |
| `클릭하세요` | 디바이스 종속적 | `선택해 주세요`, `눌러 주세요` |
| `해주세요` (붙여쓰기) | 맞춤법 오류 | `해 주세요` (띄어쓰기) |
| `보내드린` (시스템 발송) | 불필요한 높임 | `보낸` |
| `새로운` | 불필요한 수식어 | `새` |
| `~를 위한` | 번역투 | `~에 필요한`, 또는 삭제 |
| `분실하신` | 딱딱함 | `잊으셨나요?` |
| `오류가 발생하였습니다` | 모호하고 수동태 | 구체적인 에러 상황 설명 |
| `잠시만 기다려 주십시오` | 딱딱함 | `잠시만 기다려 주세요` |
| `잘못된 입력입니다` | 사용자 탓, 원인 미제공 | 구체적 에러 안내 |

## 서비스 고유 표기

화면 간 표기 불일치가 발견된 용어를 표준안으로 정의합니다.

| 표기 대상 | 올바른 표기 | 잘못된 표기 |
|---|---|---|
| 서비스 약관 | **서비스 이용약관** | 서비스 이용 약관 |
| 개인정보 방침 | **개인정보 처리방침** | 개인 정보 처리방침 |
| 수리 내용 | **수리 내역** | 수리내역 |
| 결제 내용 | **결제 내역** | 결제내역 |
| 정산 내용 | **정산 내역** | 정산내역 |
| 기본 정보 섹션 | **기본 정보** | 기본정보 |
| 보험 유무 | **보험 여부** | 보험여부 |
| 계정 확인 | **계정 확인** | 계정확인 |
| 작업 검색 | **작업 검색** | 작업검색 |
| 작업 진행 탭 | **작업 중** | 작업중 |
| 작업 완료 탭 | **작업 완료** | 작업완료 |
| 회원 탈퇴 | **회원 탈퇴** | 회원탈퇴 |
| 중복 확인 버튼 | **중복 확인** | 중복확인 |
| 아이디 플레이스홀더 | **예) wepair** | 아이디 |
| 연락처 플레이스홀더 | **010-0000-0000** | 담당자 연락처 |

## 상태값 통일 기준

UI 전반에서 동일한 상태를 표현할 때 아래 표현으로 통일합니다.

| 상태 | 권장 표현 | 금지 표현 |
|---|---|---|
| 작업 진행 중 | `작업 중` | `작업중`, `진행중` |
| 완료 | `~했어요` / `~완료` | `~되었습니다`, `~완료되었습니다` |
| 실패 | `[대상] 실패` | `[대상] 오류`, `[대상] 정보 확인` |
| 없음 (빈상태) | `아직 ~이 없어요` | `~이 없습니다`, `데이터 없음` |
| 로딩 | `잠시만 기다려 주세요` | `로딩 중입니다`, `잠시만 기다려 주십시오` |
| 저장 성공 | `저장했어요` | `저장이 완료되었습니다` |
| 전송 성공 | `전송했어요` | `전송이 완료되었습니다` |
| 삭제 성공 | `삭제했어요` | `삭제되었습니다` |
| 권한 요청 | `[목적]을 위해 [권한] 접근 권한이 필요해요` | `[권한]을 사용할 수 있는 권한이 필요합니다` |

## 띄어쓰기 규칙 요약

자주 틀리는 패턴만 별도 정리합니다.

| 규칙 | ❌ 잘못된 예 | ✅ 올바른 예 |
|---|---|---|
| 보조 동사 "주다" 분리 | 확인해주세요 | 확인해 주세요 |
| 진행형 "중" 분리 | 작업중, 처리중 | 작업 중, 처리 중 |
| 명사+명사 분리 | 기본정보, 결제내역 | 기본 정보, 결제 내역 |
| 조사 붙여쓰기 | 아이디 입니다 | 아이디예요 |
| 용언 내부 공백 | 일치 하지 않아요 | 일치하지 않아요 |
