## 3. 에러 (Error Message)

**패턴:** `-않습니다`, `-불가능합니다` 등 -합니다 체 잔존. 해결 방법 미제시 케이스 다수.
**권고:** 에러는 반드시 **원인 + 해결 방법** 구조. `-않아요` 체로 통일하고 다음 행동을 명시.

## 4. 토스트 (Toast / Snackbar)

**패턴:** `~가 되었습니다` 수동형이 12건 전부. 오타 1건 포함.
**권고:** 토스트는 **능동형 단문**이 원칙. `[대상]을 [동사]했어요.` 패턴 템플릿화 권장.

```
✗  [대상]이 [동작] 되었습니다.
✓  [대상]을 [동작]했어요.
```

**패턴:** 전부 `-없습니다` 형태. 다음 행동 안내 없이 상태만 서술하는 케이스 존재.
