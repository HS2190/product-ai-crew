# 디자이너용 — 실제 데이터 · 실제 기기에서 깨지는 상태

## 1. 실제 데이터로 깨지는 상태

- 짧은 예시 문구(홍길동)로만 그리지 않기 — 가장 긴 닉네임 · 상품명 · 버튼 문구로 말줄임 · 줄바꿈 확인
- 큰 글씨 설정, 최소 화면 폭(375 · 360), 노치 · 작은 화면, 태블릿
- 다크 모드는 제품이 지원할 때만
- 대표 화면 1개 이상에 위 상태를 실제로 보여 줌

## 2. 겹쳐 뜨는 요소 · UI 요소 동작

| 요소 | 인터랙션 노트에 적을 것 |
|---|---|
| 토스트 | 표시 시간, 여러 개가 뜰 때 겹치지 않는지 |
| 모달 | 바깥 탭 · 뒤로 가기로 닫히는지 |
| 바텀 시트 | 끌어내려 닫기, 키보드가 올라올 때 가려지지 않는지 |
| 드롭다운 | 항목이 많을 때 스크롤 · 잘림 |
| 토글 | 새로고침 후 상태 유지 |
| 탭 | 탭 이동 후 스크롤 위치 · 입력값 유지 |
| 스켈레톤 | 로딩 후 사라짐, 데이터 0건이면 빈 화면 |
| 툴팁 | 모바일 표시 방법, 화면 밖 잘림 |
| 캐러셀 | 마지막 장 → 처음 이동 |

## 3. 키보드 · OS 차이 (모바일)

- 키보드가 올라와도 입력창 · 저장 버튼이 안 가려짐 (Android 15 이상 주의)
- 뒤로 가기: iOS 왼쪽 가장자리 스와이프 / Android 제스처 · 버튼 — 같은 화면으로
- 날짜 선택: iOS 달력 · 휠 / Android 달력 창 — 저장 형식은 같게
- 권한 팝업 · 공유 창 모양이 OS마다 다름 — 우리 화면이 기대는 부분 확인
- 기본 글꼴 차이로 줄바꿈이 달라짐 — 긴 문구 여유

## 4. 오류 안내 화면

- 없는 대상(삭제된 글 · 잘못된 링크) · 서버 오류 · 네트워크 끊김 → 빈 화면 대신 안내 + 다음 행동
- 권한 거부 · 로그인 만료 안내
- 서버 점검 화면(점검 시간 · 다음 행동), 강제 업데이트 안내(스토어 이동) — 평소엔 안 보여서 빠지기 쉬움. 기획에 정의된 경우 그림

## 5. 디자인 QA 9가지 (자가 점검)

1. 시안과 같은 해상도로 캡처해 겹쳐 비교
2. 폰트가 기본 폰트로 바뀌지 않았는지
3. 색상은 눈대중 말고 색상 코드로
4. 간격 · 정렬 · 여백
5. 상태별 화면: 눌림 · 비활성 · 에러
6. 긴 텍스트: 말줄임, 레이아웃 밀림 없음
7. 화면 크기: 작은 폰 · 태블릿
8. 시스템 설정: 다크 모드 · 큰 글씨
9. 이미지: 깨짐 · 찌그러짐

- 디자인 이슈는 시안 vs 실제 캡처를 나란히, 숫자(px · 색상 코드)로
