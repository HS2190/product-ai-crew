# 타임라인 position 파라미터

출처: https://gsap.com/resources/position-parameter

| 형태 | 의미 | 예시 |
|---|---|---|
| 숫자 (절대) | 타임라인 시작 기준 초 | `3` → 3초 지점 |
| `"+=X"` | 타임라인 끝에서 X초 뒤 (간격) | `"+=1"` |
| `"-=X"` | 타임라인 끝에서 X초 앞 (겹침) | `"-=0.5"` |
| 라벨 | 이름 붙인 지점 | `"myLabel"` |
| `"<"` | **직전 애니메이션의 시작**에 정렬 | 동시 시작 |
| `">"` | 직전 애니메이션의 **끝**에 정렬 | |
| `"<X"` / `">X"` | 직전 기준 상대 오프셋 | `"<2"` → 직전 시작 2초 뒤 |
| 퍼센트 | 상대 퍼센트 (v3.7.0+) | `"-=25%"` |
| 라벨+오프셋 | 라벨 기준 상대 | `"scene1+=3"` |

기본값은 `"+=0"`(타임라인 끝) — 그래서 체이닝하면 자동으로 순차 재생된다.

퍼센트 기준이 다르다: `"+="`/`"-="`는 **삽입되는 애니메이션**의 duration 기준, `"<"`/`">"`는 **직전 애니메이션**의 duration 기준.
