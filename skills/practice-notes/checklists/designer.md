# 디자이너 체크리스트 — 실제 데이터 · 실제 기기 · 실제 조작에서 깨지는 곳

해당하는 화면에만 적용한다. 원리 · 이유는 줄 끝의 개념 문서(`../topics/`)에 있다.

## 1. 실제 데이터로 깨지는 상태

- 짧은 예시 문구(홍길동)로만 그리지 않기. 가장 긴 닉네임 · 상품명 · 버튼 문구로 말줄임 · 줄바꿈 확인 (`typography.md` 4장)
- 큰 숫자 · 큰 금액 · 빈 값 · 배지 여러 개 · 항목 수 증가를 카드 · 목록에 넣어 봤다 (`states.md` 5장)
- 숫자 표기가 바뀌는 기준값(예: 9,999+)과 빈 상태 표시(예: 별점 0.0 대신 '신규')의 종료 조건을 스펙에 적었다
- 큰 글씨 설정, 최소 화면 폭(375 · 360), 노치 · 작은 화면, 태블릿 (`size-units.md` 6 · 7장)
- 다크 모드는 제품이 지원할 때만
- 대표 화면 1개 이상에 위 상태를 실제로 보여 줌

## 2. 상태

- 버튼마다 필요한 상태를 골랐다: 기본 · 누름 · 처리 중 · 완료 · 비활성(이유 포함) (`states.md` 1장)
- 입력칸: 포커스 · 입력 중 · 입력됨 · 오류. 칸 이름은 플레이스홀더가 아니라 레이블로 (`states.md` 2장)
- 로딩은 스켈레톤 / 로더 / 진행 표시 중 이유 있게 골랐다. 알 수 없는 진행률을 지어내지 않았다 (`states.md` 3장)
- 목록 화면에 처음 비어 있음 · 불러오는 중 · 오류 · 검색 결과 0건이 있다 (`states.md` 4장)
- 수량 · 입력 개수의 최소 · 최대에서 버튼 · 안내가 정해졌다

## 3. 컴포넌트 · 겹쳐 뜨는 요소

- `component_spec`에 이름만이 아니라 동작 · 상태 · 기준값을 적었다 (`components.md`)
- 모양이 같은데 동작이 다른 요소(칩 vs 레이블)가 섞이지 않았다
- 토스트 · 모달 · 바텀 시트 · 드롭다운 · 툴팁 · 캐러셀의 닫기 · 복귀 · 겹침 동작을 인터랙션 노트에 적었다 (`components.md` 3장)
- 제스처는 이름 + 동작 + 결과로 적었다(방향 · 멈추는 위치) (`components.md` 5장)

## 4. 크기 · 글자

- 아트보드 기준 기기(1배수 논리 해상도)를 `design_spec`에 적었다 (`size-units.md` 1장)
- 크기 · 간격은 4 · 8 단위 토큰, 예외에는 이유 (`size-units.md` 5장)
- 글자 단계와 쓰임을 표로 남겼고 10px 같은 너무 작은 글자가 없다 (`typography.md` 1장)
- 상태 바 · 홈 바와 중요한 문구 · 버튼이 겹치지 않는다
- 회사 디자인 시스템 토큰이 있으면 그것만 썼다

## 5. 키보드 · OS 차이 (모바일)

- 키보드가 올라와도 입력창 · 저장 버튼이 안 가려짐 (Android 15 이상 주의)
- 뒤로 가기 · 날짜 선택 · 권한 팝업 · 공유 창처럼 OS와 만나는 화면은 iOS · 안드로이드 차이를 확인 (`platforms.md` 3장)

## 6. 오류 안내 화면

- 없는 대상(삭제된 글 · 잘못된 링크) · 서버 오류 · 네트워크 끊김 → 빈 화면 대신 안내 + 다음 행동
- 권한 거부 · 로그인 만료 안내
- 서버 점검 화면(점검 시간 · 다음 행동), 강제 업데이트 안내(스토어 이동). 평소엔 안 보여서 빠지기 쉬움. 기획에 정의된 경우 그림

## 7. 흐름

- 메뉴 구조(탭 · 메뉴)와 단계 수를 정한 이유를 남겼다. 입력이 많은 흐름은 남은 단계를 보여 준다 (`flows.md` 3 · 4장)
- 첫 화면에서 무엇을 하는 서비스인지와 다음 행동이 보인다. 화면에서 가장 중요한 행동이 가장 강조됐다
- 레퍼런스는 통째로 옮기지 않았다. 자료마다 무엇을 왜 참고했는지(정보 묶는 방식 · 색 비중 등) 말할 수 있고, 내 콘텐츠의 정보량에 맞게 바꿨다

## 8. 디자인 QA 9가지 (자가 점검)

1. 시안과 같은 해상도로 캡처해 겹쳐 비교
2. 폰트가 기본 폰트로 바뀌지 않았는지
3. 색상은 눈대중 말고 색상 코드로
4. 간격 · 정렬 · 여백
5. 상태별 화면: 눌림 · 비활성 · 에러
6. 긴 텍스트: 말줄임, 레이아웃 밀림 없음
7. 화면 크기: 작은 폰 · 태블릿
8. 시스템 설정: 다크 모드 · 큰 글씨
9. 이미지: 깨짐 · 찌그러짐

- 디자인 이슈는 시안 vs 실제 캡처를 나란히, 숫자(px · 색상 코드)로
